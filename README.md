# Shrink Curios Support

A fork of [Shrink](https://github.com/Enjarai/Shrink) adding **Curios support**.

This version allows the Personal Shrinking Device to be equipped in a **Curios slot** and still be activated using its normal hotkey.

The device can be used from either the player's inventory or its configured Curios slot, allowing the shrinking functionality to remain accessible without occupying a regular inventory slot.

This project uses ForgeGradle. Build instructions are available in the `build.gradle` file.

The licence is located at COPYING.txt, but to save you the trouble, it's GPLv3 (with one of the sounds under CC Attribution License).
